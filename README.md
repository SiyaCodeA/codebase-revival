# Workplace AI Productivity Assistant

## 1. Project Overview

The Workplace AI Productivity Assistant is an AI-powered web application designed to improve workplace productivity and simplify everyday tasks. It provides tools for generating professional emails, summarising meeting notes, planning tasks, conducting research and interacting with an AI chatbot.

The application aims to save time, improve organisation and support more efficient workplace communication.

## 2. Features

The application includes five main AI-powered features:

### 2.1 Smart Email Generator
Helps users generate professional emails based on their instructions and communication needs. Generated emails can be reviewed, edited and copied.

### 2.2 Meeting Notes Summarizer
Converts meeting notes into structured summaries, including:
- Meeting overview
- Main discussion points
- Decisions made
- Action items, owners and deadlines
- Follow-up items

Users can also regenerate an alternative summary.

### 2.3 Task Planner
Helps users break down tasks into organised plans with clear steps and priorities. Generated plans can be reviewed and edited.

### 2.4 Research Assistant
Helps users explore topics and organise information into structured responses. It offers quick and detailed response options.

### 2.5 AI Chat
Provides an interactive chat interface where users can ask questions and have follow-up conversations with the AI assistant.

## 5. Responsible AI

The application encourages responsible use of AI.

- AI-generated content should be reviewed before being used or shared.
- Users should verify important information.
- The Research Assistant does not perform live web searches or verify external sources.
- AI Chat conversations are not retained after the page is reloaded.
- The Task Planner generates plans but does not maintain a persistent task list.

AI-generated responses may contain inaccuracies and should not replace human judgement.
