# Workday Copilot

Create a modern, professional, responsive web application called AI Workplace Productivity Assistant. This must be one integrated application, not separate projects. Build a clean SaaS dashboard with a left sidebar and a main content area. Use a white or warm-neutral background, dark readable text, and a restrained blue accent. Include these navigation pages: Dashboard, Smart Email Generator, Meeting Notes Summarizer, AI Task Planner, AI Research Assistant, and Settings. The dashboard should have a welcome heading, a short explanation of the app, feature cards, quick-action links, and a recent activity section with an appropriate empty state. Create a consistent layout for all pages, accessible form labels, readable typography, keyboard-friendly controls, loading states, and useful error messages. Make the layout responsive on desktop and mobile. Include a visible responsible AI notice explaining that generated content must be reviewed. For now, build the UI and navigation structure only. Do not pretend that AI features work, do not add hard-coded fake AI results, and do not introduce unnecessary authentication, payments, or complex database requirements. Keep the project code organised so that real AI functionality can be added to each feature separately. Preserve the existing project and its design when making future changes.
